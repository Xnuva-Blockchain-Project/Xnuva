XNUV development now proceeds through normal GitHub commits.

## Official atomic-unit name

On **8 September 2026**, the existing XNUV atomic unit was formally named **Prince**, in memory of **Prince the American Akita**.

- 1 Prince = 0.00000001 XNUV
- 100,000,000 Prince = 1 XNUV

This is a terminology and wallet-display change only. It does not alter the eight-decimal monetary precision, any existing amount, supply, block history, genesis, block 1, or consensus rules.
